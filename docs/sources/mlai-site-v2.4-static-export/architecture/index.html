Framework selection, measured

Throughput figures from community benchmarks on Apple M-series hardware. The standard library is the floor; the question is how much ceiling the workload needs.

std.http.Server~32K req/sPost-Writergate std.Io.Reader/Writer interfaces. Adequate for moderate traffic; the baseline.
http.zig~140K req/sPure Zig HTTP/1.1 with routing, JSON, WebSockets, CORS, static files. dev branch tracks master.
Jetzighttp.zig coreRails-like batteries: file routing, Zmpl templates, sessions, CSRF, jobs, HTMX. Most 0.16-forward-compatible.
zzzwithin 2% of gnetio_uring / epoll / kqueue. Native TLS. Alpha quality, extraordinary ceiling — 66% faster than Zap.
Minimal server

Zig 0.17-dev, post-Writergate

const std = @import("std");

pub fn main() !void {
    const address = try std.net.Address.parseIp4("127.0.0.1", 8080);
    var server = try address.listen(.{});
    defer server.deinit();

    while (true) {
        const conn = try server.accept();
        defer conn.stream.close();
        var read_buf: [8192]u8 = undefined;
        var write_buf: [8192]u8 = undefined;
        var http = std.http.Server.init(
            &conn.stream.reader(&read_buf).file_reader.interface,
            &conn.stream.writer(&write_buf).file_writer.interface,
        );
        var req = try http.receiveHead();
        try req.respond("WDBX online", .{ .extra_headers = &.{
            .{ .name = "Content-Type", .value = "text/html" },
        } });
    }
}

std.http.Server over the new std.Io.Reader / std.Io.Writer interfaces introduced in the 0.15→0.16 transition.

Decisions

Four calls that shaped the stack

TLS termination

std.crypto.tls.Server doesn't exist yet (zig#14171). Production terminates TLS at a reverse proxy (Caddy + Let's Encrypt) or uses zzz's native TLS; tls.zig is the third-party fallback.

SSR without a framework tax

ArrayList(u8) writer for dynamic HTML, direct response-writer streaming for large pages, comptime concatenation for static fragments — zero runtime cost for anything known at compile time.

SIMD-native vector math

@Vector builtins compile distance kernels to the exact target ISA — AVX-512 on x86, NEON on Apple Silicon — with the same source. The database and the server share one binary.

One build, every platform

zig build cross-compiles static binaries for macOS arm64/x86_64, Linux, and Windows. No container, no runtime, no GC — deterministic p99s because nothing pauses.

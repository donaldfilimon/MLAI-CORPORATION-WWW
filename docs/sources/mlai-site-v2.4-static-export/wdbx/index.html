What's inside

HNSW index architecture

Hierarchical Navigable Small World graphs. O(log n) search. 95% recall at 8.2ms on 1M vectors.

Memory-mapped persistence

Swift 6.2 Span for zero-copy I/O. WAL journaling. Instant cold starts.

Scalar & product quantization

Up to 32× compression with minimal recall loss. 10B vectors addressable in 2GB RAM.

Metal GPU acceleration

Distance calculations on Apple GPU via the ABI Framework. First App Store-ready vector database.

MVCC transactions

Multiversion concurrency control. Readers never block writers; writers never block readers.

AES-256 + RBAC

Encryption at rest, role-based access control, audit-grade write-ahead log.

Concurrency model

MVCC, hash-chained

Non-blocking by construction

Writes create new versions; readers see a consistent snapshot from transaction start. Inference-heavy read traffic and background ingestion never contend.

Tamper-evident WAL

The write-ahead log is hash-chained — SHA-256 over data XOR the prior block hash — so the audit trail is immutable without taxing the HNSW index hot path.

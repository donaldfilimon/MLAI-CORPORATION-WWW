Engineering

Built like systems software, because it is.

Zig 0.17-dev core, no garbage collector

Deterministic memory management keeps p99 latency glued to p50 — no GC pauses, no jitter. Comptime specializes vector kernels for the exact target ISA.

Provenance-tagged benchmarks

Every number on this site is tagged measured, target, or reported — and the legend lives in the footer. We don't ship numbers we can't reproduce.

MVCC + hash-chained WAL

Readers never block writers. The write-ahead log is hash-chained for tamper-evident audit trails and neural backtracking through agent state.

One binary, every platform

zig build cross-compiles static binaries for macOS, Linux, and Windows. The database and its server ship as one artifact.

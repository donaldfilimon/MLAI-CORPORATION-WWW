What's inside

Tensor operations

N-dimensional tensors with automatic differentiation. SIMD-optimized CPU paths plus Metal GPU kernels.

GPU context management

Metal Performance Shaders integration, automatic kernel selection, async pipelines.

Neural network layers

Dense, Conv2D, LSTM, Attention. ReLU, Sigmoid, Softmax. Full backpropagation.

Zero-copy operations

Unified memory eliminates host↔device transfers. Span-based APIs, actor-based concurrency.

Multi-persona orchestration

Comptime specialization

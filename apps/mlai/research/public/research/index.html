Research areas

AI & agent behavior

Understand how Abbey and ABI route requests, produce local responses, and expose bounded checks.

Practical applications: Evaluate assistant workflows with explicit behavior, provider and review boundaries.

Availability: Local deterministic routing and completion are implemented; model quality requires separate evaluation.

WDBX memory & retrieval

Durable records, searchable vectors and inspectable retrieval for applications that need continuity.

Practical applications: Build document recall and decision-history prototypes with explicit source ownership.

Availability: Rust persistence, HNSW search and episode-store components are implemented.

Explore research and limitations →

SEA evidence selection

Select a bounded set of relevant records before assembling an assistant context.

Practical applications: Prototype project recall or document assistance without placing every available record in a prompt.

Availability: Eight-signal selection, task-specific scoring and bounded prompt assembly are implemented.

Explore research and limitations →

GPU & compute

Inspect native vector-operation support and explicit CPU fallback.

Practical applications: Assess whether a target Apple workstation can use the optional Metal DOT path.

Availability: CPU vector operations and optional macOS Metal DOT dispatch are implemented.

MCP integrations

Expose bounded ABI operations through a documented tool interface.

Practical applications: Evaluate a local integration from an MCP client into the ABI tool catalog.

Availability: The twelve-tool stdio JSON-RPC contract is implemented.

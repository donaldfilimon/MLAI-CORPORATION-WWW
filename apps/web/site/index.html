ABI

Local developer framework for routing assistant requests and assembling inspectable context.

Requires nightly Rust and the sibling workspaces documented upstream. Local template completion does not establish model quality.

Abbey

A local document workspace with assistant context.

Requires Node 24, Bun 1.4, uv with Python 3.11–3.13, Java 21+ and LibreOffice. A local model is optional; this website does not provision an assistant session.

Abbey local setup · Supporting research

WDBX

Rust components for durable records, vector retrieval and inspectable provenance.

Prepare its source workspace before integration. Storage integrity does not establish truth; the reference cluster protocol does not establish production sharding.

WDBX source and setup · Supporting research

Quasar

A local v1 website builder: generate a Next.js project and preview it on your own machine.

Requires Bun 1.4, Anthropic credentials, a local service and Expo app. Hosting, deploy adapters and authentication are outside this version.
